# Archived mascot concepts

The 32x32, early 40x40, and tall concept images in this directory were direction-finding work, not production animation frames. The owner ultimately selected the secondary 40-point chibi direction and froze it under `../production/`.

All 12 superseded concept PNGs were removed from the working tree on 2026-07-28 to keep the project unambiguous. The comparison outcomes, prompts, and failure analysis remain in `../../DesktopMascot.md`; the original binaries remain recoverable from Git history through commit `0f292ec`.

Do not add new base-character concepts for version 0.1. Continue with the animation-atlas specification in issue #3 using `../production/mascot-base-chibi-40pt-at2x-80px-final.png`.
